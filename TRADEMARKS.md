# Roadleaf name and icon

The code is open source under GPL-3.0-only (see `LICENSE` and `NOTICE`). The **Roadleaf** name, logo and app icon are not covered by that license; they identify the official app published by fdmcadmin.

## You may

- Build, use, study, modify and share Roadleaf's code under the GPL.
- Say that your project is "based on Roadleaf" or "a fork of Roadleaf", as long as it is clear that it is not the official app.
- Use the name in plain text to refer to the original project, for example in reviews, articles or tutorials.

## Please don't

- Publish an app, fork or build under the name Roadleaf, a confusingly similar name, or with the Roadleaf icon or logo.
- Use the application ID `app.roadleaf` (or `app.roadleaf.*`) for a distributed build.
- Suggest that the original author made, endorses or supports your version.

Forks should choose their own name, icon and application ID. The GPL's section 7 terms in `NOTICE` also require modified versions to be marked as different and to keep the author credit.

Questions about using the name can be raised as an issue on the official repository.
