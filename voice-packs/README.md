# Roadleaf Weighted 15×15

In Roadleaf Main 0.3.46, open **Voice → Narrator**, select **Supertonic 3**, and tap **Download 30 weighted voices**. If you already have the TSV, tap **Import weighted voice pack** and open it from Downloads. Use **Set up Supertonic 3** if the shared model is still needed.

The file contains 15 male and 15 female voice recipes. Each recipe blends rows of the stock Supertonic 3 styles and preserves the weighted row lengths. The phone computes the weighted styles and generates speech locally after setup. The file carries recipe percentages only. Supertonic 3 and its locally produced styles remain subject to the [Supertone model terms](https://huggingface.co/supertone-oss-archive/supertonic-3/blob/aafc6e3/LICENSE).

`M-Weighted-01` uses 90% M3 and 10% M1. `F-Weighted-01` uses 90% F4 and 10% F5. Existing cast assignments can keep their stock voice IDs or select the new recipes when ready.
